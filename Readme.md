# ⚽ Football Transfer Market Analysis using Excel

## 📊 Project Overview

This project analyzes international football transfer activity using Microsoft Excel.

The analysis focuses on transfer movements between countries, transfer volumes, club-to-club compensation, European transfer activity, country-level transfer performance, and the leading football transfer markets.

The project uses raw football transfer data and transforms it into structured analytical tables and visualizations using Excel.

---

## 🎯 Business Problem

Football transfer data contains valuable information about player movements between countries and the financial value of transfers.

However, raw transfer data can be difficult to interpret without proper analysis.

The objective of this project is to analyze international football transfer activity and identify:

- Countries with the highest number of incoming transfers
- Countries with the highest number of outgoing transfers
- Transfer activity across continents
- European transfer trends
- Net player movements between countries
- Transfer compensation values
- Top football transfer markets

---

## 🗂️ Dataset

The dataset contains international football transfer information for the following seasons:

- 2021/2022
- 2022/2023

The main dataset contains approximately 3,350 transfer records.

### Main Fields

- Season
- Transfers Incoming
- Incoming Continent
- Transfers Outgoing
- Outgoing Continent
- Number of Transfers
- Total Club-to-Club Compensation

A separate country reference table was also used to associate countries with their respective continents.

---

## 📑 Excel Workbook Structure

The final Excel workbook contains the following analytical sections:

### 1. Database

Contains the primary football transfer dataset.

### 2. Countries

Contains country and continent information used for geographical analysis.

### 3. European Transfers

Analyzes overall European transfer activity across seasons.

### 4. European Transfers by Country

Provides country-level analysis of:

- Incoming transfers
- Outgoing transfers
- Net number of players
- Incoming transfer value
- Outgoing transfer value
- Net transfer value

### 5. Visualization – Top 5 Countries

Highlights the top football transfer markets based on:

- Number of incoming transfers
- Average transfer fee
